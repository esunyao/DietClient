# UI 校准规格

本文件是本轮 UI 校准的目标，不是已实现或已视觉验收的声明。主依据为只读 `20261002ui二次设计` 中手机 C 端 `最终样板_v1`、`平板B端_最终样板_v1` 的最终 SVG、完整稿和设计说明，以及用户提供的手机个人首页、平板机构首页两张目标图；新版需求 PPT 补充业务语义，React Native 仅辅助未绘流程。实际命令、结果与未验收项另记于 [根说明](../README.md) 和交付说明。

## 逻辑尺寸与字阶

尺寸均为 Flutter 逻辑像素。参考 PNG 为 2 倍导出，不能把位图像素当作逻辑尺寸；下表是默认文字缩放下的校准基准，不是锁死页面或文字高度。

| 项目 | 手机个人首页 | 平板机构首页 |
|---|---|---|
| 参考画布 | 430 × 960 | 1194 × 834 |
| 左右页边距 | 24，内容宽 382 | 32，可用内容宽 1130 |
| 主体分栏 | 单栏 | 主栏 754、侧栏 352、栏距 24 |
| 记录入口卡 | 横向深绿卡，约 144 高 | 采集入口降权，不挤占主栏首位 |
| 营养卡 | 约 220 高 | 约 210 高 |
| 今日餐食 | 约 83 高的独立卡 | 三行列表区约 236 高 |
| 7 日摘要 | 随内容组织，不挤压餐食 | 约 81 高 |
| 主导航 | 悬浮底栏约 62 高、圆角 31，左右 24 | 顶栏约 84 高，横向文字 tab |

| 字阶 | 默认字号 | 用途 |
|---|---:|---|
| 主标题 | 28 | 首页和主入口标题 |
| 次标题 | 23 | 二级页面标题 |
| 区块标题 | 19 | 卡片与内容分区 |
| 正文 | 14–16 | 操作、说明和列表内容 |
| 辅助文字 | 12–13 | 日期、来源、状态与演示标识 |
| 主数值 | 39 | 主要能量数值，单位和辅助数值保持次级层次 |

沿用系统中文字体回退、本地 SVG 插画和统一图标入口。数字可使用等宽数字特性，但不能为对齐而改写真实数值或补齐未知数据。

## 约束、滚动与安全区

- 使用实际父级约束、固定逻辑 tokens 和必要的换行；不引入 ScreenUtil 式全局缩放，不用缩小文字掩盖布局错误，不关闭系统文字缩放。
- 真实系统状态栏、手势区和键盘由平台与 `SafeArea`/insets 处理，只消费一次；不画假状态栏，不再叠加设计图中的系统栏高度。
- 标题 header 固定，业务内容独立滚动。主导航和页面 footer 的覆盖范围统一预留，末项、错误提示与提交操作均须可见、可点；不重复增加 bottom inset。
- 参考卡高和导航高在默认字号下校准；大字、长标题、窄屏和键盘场景允许自然增高或重排，不裁切文字、不产生横向溢出。
- 840 以下使用手机底栏，适用的双栏以原 1024 窗口语义对应的实际可用宽度判断，不能忽略父级 padding。窗口只改变布局，不改变个人/机构身份。

## 首页内容层级

手机个人首页依次为日期、标题与头像，横向记录卡，手工/历史/档案三个快捷入口，营养卡和独立餐食卡。餐食保留时间、来源或 AI 估算、分析/确认状态等信息，不用放大的通用列表行替代参考层级。

平板机构首页左侧依次为营养、今日餐食、7 日摘要；右侧为机构晚餐、报告和隐私。机构晚餐不放到主栏顶部，采集不抢占机构用户的首要阅读任务。宽屏个人模式和窄屏机构模式也要可用，不能通过屏宽偷换身份。

演示标识须清楚，但应融入标题辅助文字或相关内容，不为所有页面额外堆叠一整行提示。保留现有返回来源栈、四主入口、设置和退出能力，不用装饰性改动删除真实登录或既有内存交互。

## 材质、库与数据语义

主内容使用实体卡片和克制的绿色层次；玻璃仅用于导航、浮层及必要操作区。玻璃继续通过 `GlassBackdrop`/`GlassSurface` 封装现有 Flutter 库：关闭、标准磨砂、增强折射三档，能力不足或无障碍偏好下回退。保留 Windows 背景单次装配与切档状态，Web 磨砂不能标成实时折射。

沿用 [现有库选择](library.md) 和 [pubspec.lock](../pubspec.lock)，不新增或升级依赖，不迁 RN 原生 UI、桥接或自建渲染引擎。共享几何与字阶归属 [diet_ui](../packages/diet_ui/AGENTS.md)，页面组合归属各 [feature](../lib/features/AGENTS.md)，路由和导航装配归属 [app](../lib/app/AGENTS.md)。

已知摄入、未知营养、分析中、计划和机构待确认继续区分；未知不补零，计划/待确认不入账，不编造评分。既有演示值和修正联动见 [迁移对照](migration.md)，真实会话边界见 [登录说明](authentication.md)。

## 复核口径

聚焦检查 430 与 1194 逻辑宽度、必要的窄屏/大字、导航与滚动遮挡，以及共享状态和既有登录门控回归；不建立逐页 golden 或全平台矩阵。格式、静态分析、聚焦测试和必要的一次 Web 或 Windows 编译由集成阶段记录，Android 与真机视觉、功能、性能由用户验证。编译成功不能证明与目标图一致。
