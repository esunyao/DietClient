# 配餐

三组共享套餐样例支持比较、整套餐替换和加入晚餐计划；保存只改变计划，不增加实际摄入。

均为2026年10月2日场景的本地演示，无网络请求或持久化。手机依次展示晚餐背景、三方案比较、菜品份量、预计营养与加入计划，辅助依据在下方；宽屏通过共享 AdaptiveColumns 将方案与菜品置于主栏，限制核对与食堂入口置于侧栏。方案卡支持选中语义和大字/窄屏换行，菜品份量明确为计划值。

页面复用 diet_ui 的固定标题与滚动内容，不额外消费安全区；局部展示见 [meal_plan_widgets.dart](../presentation/widgets/meal_plan_widgets.dart)。视觉参照430×960手机与1194×834平板样板，实际视觉与真机验收仍由用户完成。
