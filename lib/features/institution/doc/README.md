# 机构餐食

Android/Windows 真实模式没有机构菜单、成员身份、选餐与餐食同步契约，入口显示暂未支持，不将虚构机构餐计入本人摄入。隐私遮罩仍可使用。以下演示仅保留给本轮未迁移的 Web 与显式 UI 预览。

菜单选择与实际用餐核对分开。花生配料与交叉接触未核对前阻止选餐确认；同步页另需本人归属与食用比例，确认后共享状态更新且防止重复入账。

均为2026年10月2日场景的本地演示，无网络请求或持久化。手机顺序布局，宽屏通过共享 AdaptiveColumns 组合主内容与侧栏：菜单以可选套餐和过敏风险为主、选餐预计营养为侧；同步以来源状态和机构菜品为主、归属与食用量核对为侧。使用16圆角实体表面、紧凑菜品行和明确的未提交／未入账状态；标题、滚动和安全区由 AppPage 处理。
