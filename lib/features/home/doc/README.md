# 首页

个人首页依次展示横向深绿记录入口、手工/历史/档案三个快捷入口、今日营养与独立餐食卡；宽屏仍保留个人体验，不将记录入口铺满整页。机构首页以营养、餐食、近7日摘要为主，宽屏将待确认晚餐、报告、隐私提示放在右侧；窄屏顺序堆叠，拍照与补录仍为次级入口。

日期、标题与演示标记由共享 AppPage 固定展示；首页不重复处理安全区。营养与餐食复用内部展示组件，餐食保留时间、来源和分析状态，餐盘标为示意而非实际照片。

统计直接来自内存演示状态的 todayTotal、todayMeals 与 trend(7)。未知值保留未知，近7日日均只除以有数值的记录日；计划与待确认机构餐不入账，不计算虚构评分。点击记录进入详情，保存修正后首页与近7日摘要自动更新；旧报告保留待更新提示。

个人首页标题24、上部左右20；餐食仍保留原24边距及原组件、数据和交互。深绿入口使用 `assets/images/home_capture_bowl.png`，这是 AI 生成的入口装饰，不是真实餐食记录照片。三个快捷入口在正常手机宽度横排，窄屏或大字自然增高。个人营养使用只读 UI 演示目标1800 kcal、蛋白质90g、碳水250g、脂肪60g，明确标记演示；百分比与超额数值保留真实结果，仅条长钳制，未知仍报未知。机构营养不采用这些目标。
