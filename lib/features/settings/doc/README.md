# 外观设置

沿用绿色主题、分组表面和有界玻璃示例；默认标准磨砂。增强不可用时回退，减少透明度使用实体表面，减少动态同时遵循系统无障碍设置。

Android/Windows 使用 SharedPreferencesAsync 的单个版本化外观记录，只保存玻璃档位、减少透明度和减少动态。启动异步加载不改变业务会话；加载期间忽略重复加载与保存，避免迟到读取覆盖保存。未知档位、无效 JSON 或类型回退默认值。读取失败可重试，写入失败保留此前值并明确提示，重试同一操作即可重新保存。不会使用普通偏好保存 Token 或健康数据。

真实模式的重置只恢复外观，不清除餐食、健康资料、AI 同意或会话。个人/机构内个人是显式显示选择，不赋予机构身份；信息遮罩仅为临时显示。Web 保留原有内存演示及演示重置。

回归见 [preferences_functional_test.dart](../../../../test/preferences_functional_test.dart)，覆盖重启恢复、未知值、失败恢复与重置隔离；实际设备持久化和视觉仍需验收。
