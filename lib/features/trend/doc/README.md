# 营养趋势

Android/Windows 使用真实 daily-trend，按当前日期切换 7/30/90 日和营养素；日期缺失、没有餐食及缺少指标均保留未知，不画成零。明确记录的零营养值仍保留为零。日均仅除以该营养素有数值的记录日，图表与逐日读数使用相同数值。图表继续通过 diet_ui.NutritionBarChart 封装，提供加载、错误重试与空缺说明。Web 保留以下演示分支。

使用共享记录切换7/30/90日和营养素；未知值保留空缺，以有数值记录日为均值分母。图表依赖仅通过 diet_ui 使用。

均为2026年10月2日场景的本地演示，无网络请求或持久化。手机按周期/营养素、每日图表、记录覆盖、口径与报告入口排列；宽屏通过共享 AdaptiveColumns 将图表与完整度置于主栏，日均公式、阅读说明与报告置于侧栏。下方逐日表保留所有日期，提供图表以外的读数方式。

周期与营养素筛选复用 diet_ui.AppSegmented。[局部展示组件](../presentation/widgets/trend_widgets.dart)承载覆盖、口径和逐日表，不直接导入第三方图表库；图表仍由 diet_ui 封装。页面复用公共固定标题与独立滚动，不重复消费安全区。视觉参照430×960手机与1194×834平板样板，实际视觉与真机验收仍由用户完成。
