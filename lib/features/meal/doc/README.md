# 餐食

以绿色最终样板的历史、单餐详情和修正页为主要依据，使用共享 demo store 的餐食模型。历史支持日期、餐别、文本筛选、重置和逐批展示；详情区分分析状态、来源、待确认及未知营养。

修正表单通过 mealId 读取原餐；不传 mealId 时为手工新建，字段和营养初始为空，用餐日期采用共享演示日。编辑草稿在保存前不会改变统计，返回时对未保存输入进行确认。保存明确写入内存演示，关联页面读取同一状态，旧报告标记需更新。

提供设计说明指定的午餐煎鱼150g改120g样例。其他菜品或重量修改不推测营养，清空为未知并由用户核对整餐数值。未填写指标保留空值；不接入后端、真实识别或持久化。
