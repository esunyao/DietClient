# 营养报告

Android/Windows 真实模式的报告生成、历史版本和导出显示暂未支持；不使用本地生成结果冒充真实报告。真实营养汇总在首页和趋势提供。以下演示只保留给本轮未迁移的 Web 与显式预览。

共享报告支持原版本摘要预览和内存中新版本生成；原始数据变化只标记旧版本需更新，不改写其日均值。

均为2026年10月2日场景的本地演示，无网络请求或持久化。手机依次展示最新报告、本期摘要、独立摘要入口和历史版本；宽屏通过共享 AdaptiveColumns 将摘要与当前能量图放主栏，历史与版本说明放侧栏。图表明确为当前数据，旧报告日均保持原版本；逐日值可展开，不只依赖颜色或悬浮读数。

[局部展示组件](../presentation/widgets/report_widgets.dart)提供摘要、覆盖与版本卡。固定生成操作由公共 AppPage.footer 承载，始终标注内存演示且不执行导出或分享；当前无可用能量记录时关闭生成，避免把未知生成成0。现有报告不会因此改写。

参照430×960手机与1194×834平板样板；不复制设计中尚未接入的虚构“生成中”任务。实际视觉与真机验收仍由用户完成。
