# 个人资料与健康档案

按 C/B 端绿色样板校准身份卡、健康档案/报告/历史三项快捷入口、行内基础资料和双列健康摘要。手机保持紧凑单列，宽屏将个人资料与机构服务分栏；机构模式补充虚构机构食堂菜单、同步和现有隐私遮罩入口，不编造健康评分或真实邮箱验证状态。

基础资料编辑与五类记录（身体测量、目标、过敏、疾病、饮食限制）继续使用统一 demo store 的共享内存状态，返回列表和个人页可查看更新。档案默认只展示五类必要摘要，展开后查看现有记录、删除确认与添加入口；手机使用独立列表卡，宽屏使用带分隔的分组列表。新增记录从空白表单开始，保留必要字段、日期校验和未保存返回确认；编辑、添加和 AI 开关主操作固定在底部。基础资料与测量记录分开保留。

空记录表达尚未填写，不表示已确认没有疾病或限制。AI 开关仅演示共享状态，关闭时提示确认，不构成真实授权或撤回。所有修改重启恢复，不发送网络请求，不使用存储或原生权限。
