# 个人资料与健康档案

按 C/B 端绿色样板校准身份卡、健康档案/报告/历史三项快捷入口、行内基础资料和双列健康摘要。手机保持紧凑单列，宽屏将个人资料与机构服务分栏；机构模式补充虚构机构食堂菜单、同步和现有隐私遮罩入口，不编造健康评分或真实邮箱验证状态。

真实账户接入 Orion 基础资料 GET/PATCH、五类健康记录 CRUD 和同意记录 GET/POST；姓名、邮箱来自 self，姓名只读。基础资料与测量历史分开保留，各类请求独立加载、报错和刷新。新增、编辑保留输入与未保存返回确认，删除需确认。未知资料不回退演示；PATCH 空值表示保留，不提供伪清空操作。五类表单以契约枚举、单位、范围与日期关系校验。

头像点击进入选择、方形裁剪、预览确认流程；Android 提供系统相机与丢失选图恢复，Windows/Web 只选图。上传使用 presign、独立无认证 PUT、confirm，失败保留裁剪结果供重试。AI 同意只追加，政策版本 1.0；最新记录按时间和精确 ID 决定，版本不一致需重新确认。Android/Windows 饮食历史接入真实餐食，报告与机构服务暂未支持；Web 保留原有页面。
