# 个人资料与健康档案

按 C/B 端绿色样板组织身份卡、健康档案/报告/历史快捷入口、基础资料、健康摘要、AI 数据与隐私和设置。机构模式补充虚构机构食堂菜单与同步入口；个人页不编造健康评分。

基础资料编辑与五类记录（身体测量、目标、过敏、疾病、饮食限制）使用统一 demo store 的共享内存状态，返回列表和个人页可查看更新。新增记录从空白表单开始，校验必要字段及日期；删除需确认。未保存返回可继续编辑，当前输入不会静默丢失。基础资料与测量记录分开保留。

空记录表达尚未填写，不表示已确认没有疾病或限制。AI 开关仅演示共享状态，关闭时提示确认，不构成真实授权或撤回。所有修改重启恢复，不发送网络请求，不使用存储或原生权限。
