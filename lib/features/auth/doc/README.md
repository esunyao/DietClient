# 登录与认证辅助流程

使用新版绿色主题、统一标题字阶、表单卡片与辅助流程面板展示登录、注册、邮箱验证和验证结果，信息结构参考 RN 辅助流程。真实登录仍保持独立布局与清晰身份服务说明，不套用业务演示标签或预先显示验证成功。本轮将登录接入真实 Authentik/OIDC，启动先登录；应用层组合配置、执行器和内存会话，presentation 复用表单外观。平台边界及验证状态见 [登录说明](../../../../doc/authentication.md)。

注册、邮箱验证和验证结果仍为演示，不创建账号或发送邮件。真实登录不迁 MFA、业务 API、Token 刷新或持久化；其他业务页面继续使用内存样例。输入的真实登录凭据只用于已配置的身份提供方，不作为样例保存。
