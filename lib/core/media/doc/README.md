# 图片选择与恢复

统一调用 image_picker，避免头像和餐食页面重复消费 Android retrieveLostData。恢复前核实原账户、用途及餐食目标；无法确认归属则丢弃，恢复本身不自动上传。Windows 仅提供选图，不新增桌面相机。

检查实际 JPEG、PNG、WebP 类型与可解码性，按调用方大小限制拒绝超限输入，像素超过2500万时提示重新选择。图片处理使用已有 image 库，不手写裁剪引擎。头像仍使用独立方形裁剪、512 PNG 与预览确认；餐食照片保留完整画面。
