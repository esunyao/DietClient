# 会话与可选恢复

Android/Windows 的已验证会话在内存使用，到期前主动刷新；并发续期合并为一次，轮换后替换刷新令牌。稳定登录代次仅在登录/退出/换号时变化，正常续期不清空资料、查询或正在编辑的输入。

登录默认不记住，勾选后才把刷新令牌和必要身份校验上下文存入系统安全存储。记录绑定 API 与身份配置，不保存密码。启动通过刷新验证恢复，期间不开放业务页面；网络失败保留重试机会，失效或身份不符则清理。存储失败不回退明文，保留可用的内存会话并明确提示。

退出先清理当前应用状态并阻止旧请求回写，再清除保存记录；不代表全局 SSO 注销。Web 保持前序内存登录，不启用本轮恢复和刷新，显式预览不构造会话。调试输出不显示凭据或 Token。
