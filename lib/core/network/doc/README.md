# 业务网络

独立 Dio 请求 Orion 与 NutriMemo，不共享登录 Cookie。API_BASE_URL 由编译参数注入，拒绝示例 invalid 域名。只允许固定用户侧相对路径、查询参数和创建采集所需的幂等请求头；Bearer仅发往配置API源，禁用自动重定向，配置连接与读写超时。

请求前核对并续期会话，GET遇到401至多刷新重试一次；写请求不自动重放。账户由稳定登录代次隔离，正常轮换不替换业务客户端，退出/换号后的结果丢弃。

响应以plain文本接收，解码前保护健康、同意、餐食、条目和图片主键，避免数字精度损失。错误不输出服务端原文或凭据。对象存储PUT使用独立无认证客户端，保留必要预签名请求头、进度与取消，不携带业务Bearer/Cookie。

HTTP 和业务信封错误使用本地中文提示，区分输入校验、权限、资源缺失、状态冲突、文件限制、频率限制和服务不可用；超时、取消与连接失败单独提示。ApiFailure 保留 HTTP status，业务信封失败另存 code，不展示服务端 message。业务 code 401 与 HTTP 401 使用相同会话保护：GET 至多续期重试一次，写入不重放，迟到的旧令牌拒绝不清除新令牌。
