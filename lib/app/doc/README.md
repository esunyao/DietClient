# 应用装配

MaterialApp.router 使用简体中文与绿色主题，GoRouter 注册四个主入口及辅助页。窄屏主页面使用悬浮四导航，840以上使用顶部导航；二级页保留返回栈与固定操作区域。

本轮接入启动登录门控：登录完成后进入原有业务演示，业务样例与内存登录会话分开管理。配置与平台流程见 [登录说明](../../../doc/authentication.md)；真实登录状态不能由演示身份卡或模式选择推断。

系统减少动态与应用偏好共同控制动画。机构共享平板可全局隐藏个人内容；恢复只是演示操作，不代表真实身份核验。未知路径提供首页恢复入口。
