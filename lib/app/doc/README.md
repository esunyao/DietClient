# 应用装配

MaterialApp.router 使用简体中文与绿色主题，GoRouter 注册四个主入口及辅助页。窄屏主页面使用四项悬浮导航，840及以上使用横向文字顶部导航；二级页保留返回栈与固定操作区域。

启动登录门控保留：登录完成后进入原有业务演示，业务样例与内存登录会话分开管理。配置与平台流程见 [登录说明](../../../doc/authentication.md)；真实登录状态不能由演示身份卡或模式选择推断。AppShell 只读取 demoProvider 展示个人或机构信息，不因窗口宽度切换体验身份。

手机底栏在真实底部安全区上方16，左右24，默认62高与圆角31，选中项为浅绿图标文字胶囊。窄屏不再占用一行常驻退出按钮；设置由“我的”入口可达。宽屏顶部导航默认84高，使用横向文字 tab，保留设置按钮与个人菜单；菜单及 AppPageScope.onLogout 使用同一退出回调，仍仅清理当前应用认证网关和内存会话，不注销单点登录。

所有平台使用一条 GlassBackdrop 背景路径，真实页面只装配一次，导航独立覆盖；Windows 沿用背景捕获，切档不更换背景子树。文字放大时导航自然增长，AppPageScope 使用相同高度避让，inset 不含系统安全区。AppPage 统一消费安全区，固定标题与 footer，仅业务内容独立滚动。目标几何见 [视觉规格](../../../doc/ui-spec.md)，玻璃后端契约见 [设计系统](../../../packages/diet_ui/doc/README.md)。

系统减少动态与应用偏好共同控制动画。机构共享平板可全局隐藏个人内容；恢复只是演示操作，不代表真实身份核验。未知路径提供首页恢复入口。
