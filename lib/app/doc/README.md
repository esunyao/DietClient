# 应用装配

MaterialApp.router 使用简体中文与绿色主题，GoRouter 注册四个主入口及辅助页。窄屏主页面使用四项悬浮导航，Windows/Web 在840及以上使用左侧玻璃侧栏，其他平台宽屏保留横向文字顶部导航；二级页保留返回栈与固定操作区域。

Android/Windows 启动先恢复可选的已记住登录，恢复中与失败重试使用独立页面，不提前装配业务页。成功后保留原站内目标，认证页转首页；恢复失败可重试或清除本机登录重新登录。Web 保留前序门控。真实登录状态不能由演示身份或体验模式推断。

AppShell 与首页从 core/presentation 共享真实姓名/头像，资料接入 Orion，餐食和营养汇总接入 NutriMemo；无接口的报告、配餐及机构写入显示暂未支持。只有 Web 显式预览使用演示身份、零业务请求。体验模式仍显式选择，不因窗口宽度变化；外观设置由独立偏好存储负责，不重置真实账户数据。

手机底栏在真实底部安全区上方16，完整态最大340×58、图标22/文字11；收紧248×48纯图标22，迷你184×44四图标18，始终留在屏内。窄屏不再占用一行常驻退出按钮；设置由“我的”入口可达。其他平台宽屏顶部导航默认84高，使用横向文字 tab，保留设置按钮与个人菜单。菜单及 AppPageScope.onLogout 使用同一回调，清理当前应用会话与已保存的记住登录信息，不注销其他 SSO 应用。

主体用户纵向滚动累计24开始收紧、120达到迷你，反向12、回顶或切主页面恢复。忽略嵌套、横向、越界及程序化滚动；按住导航暂停收起。迷你首手势只展开，完整栏按住当前泡横拖仅预览，抬起吸附提交一次，取消复位。

所有平台使用一条 GlassBackdrop 背景路径，真实页面只装配一次，导航独立覆盖；Windows 沿用背景捕获，切档不更换背景子树。文字放大时导航自然增长，AppPageScope 使用相同高度避让，inset 不含系统安全区。AppPage 统一消费安全区，固定标题与 footer，仅业务内容独立滚动。目标几何见 [视觉规格](../../../doc/ui-spec.md)，玻璃后端契约见 [设计系统](../../../packages/diet_ui/doc/README.md)。

系统减少动态与应用偏好共同控制动画。机构共享平板可全局隐藏个人内容；恢复只是演示操作，不代表真实身份核验。未知路径提供首页恢复入口。

Windows/Web 侧栏外边距12、圆角24、紧凑宽96、展开宽216，图标22、紧凑文字11；正文固定左预留120，展开覆盖正文，不重新挤压页面。悬停120ms展开、移出180ms收起，完整展开240ms/收起200ms，统一缓动进度可中途反向且按剩余进度完成；同目标事件不重启动画。入口单图标连续移动、固定槽位文字淡化；`accountBuilder(double expansion)` 传连续进度，账户菜单与头像保持同一实例，姓名固定宽度淡入、长名省略且高度随系统文字缩放增长。键盘焦点和账户菜单保持展开，非悬停输入点击顶部标识切换，导航点击始终选择。短视口整体滚动，设置与账户仍可达；减少动态（含运动途中启用）直接切换。背景和页面树跨断点与玻璃切档保持稳定。

`WEB_UI_PREVIEW=true` 只在 Web 生效：默认首页，业务深链接可访问，登录/注册/验证页回首页；不创建 OIDC 会话、不构造认证网关。所有业务页上方显示“Web UI 预览 · 未登录”，外壳及个人页隐藏退出，机构隐私遮罩仍可操作。默认及非 Web 构建保留登录门控。
